Royal Spice Restaurant Website

A premium, fully responsive restaurant landing page built using HTML and CSS. This project showcases a modern UI design inspired by real-world restaurant brands.

Features:
- Elegant and modern landing page design
- Multiple food sections (Pakistani, Chinese, BBQ, Fast Food, Desserts)
- Hero section with strong branding
- Image gallery for food presentation
- Contact form for table reservations
- Fully responsive layout for all devices

This project was created as part of front-end development practice to improve UI/UX design skills and build real-world website layouts.

Technologies Used:
- HTML5
- CSS3 (Flexbox + Grid)
